# Sujita's Birthday Surprise

A small, self-contained birthday experience made with HTML, CSS, and JavaScript. No build step or server is needed.

## Run locally

Open `index.html` in a modern browser. Music starts only after clicking the music button. No photos are uploaded or stored by this page.

## Publish with GitHub Pages

Create a public repository and add these files at its root. In the repository settings, enable GitHub Pages and choose the `main` branch and `/ (root)` folder. The site will be available at the Pages URL GitHub provides.
